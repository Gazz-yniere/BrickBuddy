PRENDRE EN MAIN

Installe ton propre atelier.

1. Configure l'accès

Copie le fichier .env.example en .env, puis renseigne une clé de session et un mot de passe. La clé Rebrickable est facultative.

Voir la configuration →

2. Lance l'application

Utilise Python et SQLite en local, ou démarre le conteneur avec Docker Compose. Les données restent sur ta machine.

Installation locale →
Installation Docker →

3. Construis ta collection

Ajoute un set, suis les pièces trouvées et utilise les filtres pour retrouver ce qu'il te manque.
