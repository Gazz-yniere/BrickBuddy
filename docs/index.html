PRENDRE EN MAIN

Installe ton propre atelier.

1. Configure l'accès

Copie .env.example en .env, puis renseigne une clé de session aléatoire et un mot de passe d'au moins 12 caractères. La clé Rebrickable est facultative.

Voir la configuration →

2. Lance l'application

Utilise Python et SQLite en local, ou démarre le conteneur avec Docker Compose. Les données restent sur ta machine.

Installation locale →
Installation Docker →

3. Construis ta collection

Sans clé Rebrickable, ajoute un set dans « Mes sets » pour saisir ses pièces, puis active « Suivre » pour les réunir.
